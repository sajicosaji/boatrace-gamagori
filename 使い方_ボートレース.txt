【今の状態】
------------------------------------------------------
  📝 記録モード（実弾は判定待ち）
  ・予想は新モデル v5。Discord には「単勝の妙味」があるレースだけ届く

  ・実弾に進むかどうかは 判定ルール.md の基準で決める（300点たまったら判定）

【毎レース使うもの】
------------------------------------------------------
1_予想.bat
  -> ダブルクリックで起動
  -> 日付・レース番号を入力 -> 予想表示 -> Discord送信
     日付は Enter で今日の日付が自動入力される
     レース番号を Enter だけにすると当日の全レースを一括予想

2_本日自動Discord.bat
  -> 当日の全レースを自動送信（PCを付けっぱなしにしておく必要あり）
     ※ 普段は GitHub Actions が自動でやるので不要

3_結果確認.bat
  -> 当日（または指定日）の予想と結果を照合
  -> ◎1着的中率 / 単勝の妙味の記録上の収支 / 確定オッズで見直した期待値 を集計

【Discordに届くもの】
------------------------------------------------------
  締切5分前（妙味があるレースだけ）:
    💡 単勝の妙味あり（📝記録モード・実弾は判定待ち）
    ◎○▲△ と各艇のモデル勝率・単勝オッズ
    💡 単勝 3号艇 9.5倍（勝率推定14% → 期待値1.33）
    📎 2連単の本線（確率順・参考）
  夜（21:50ごろ）:
    その日の結果・妙味の記録上の収支・累計と判定までの残り点数

【予想の仕組み（v5）】
------------------------------------------------------
  データ: ボートレース公式（mbrace）の番組表・競走成績
          2021/1〜の蒲郡 13,704レース
  ・「そのレース時点で分かっていた情報だけ」で学習（旧モデルは学習データに
    未来の成績が混入していて、1号艇を大きく過小評価していた）
  ・1着・2着・3着でそれぞれ別の計算式（旧モデルは同じ式の使い回し）
  ・使う情報: 艇番 / 全国・当地勝率 / 級別 / モーター・ボート2連率 / 体重 /
    年齢 / 展示タイム / 今節成績 / 直近3節の成績・ST / 艇番別の過去成績 / 風・波

  精度（学習に使っていない期間。数字が小さいほど良い）:
                              v5モデル   確定オッズ（市場）
    2024/7〜2025/6 2,492R       1.157       1.175
    2026/8/11〜10/29 480R       1.145       1.165
  → 勝率の予想は確定オッズより正確。オッズを見ない買い方（◎の単勝、
    上位3艇ボックス等）はどれも回収率100%未満（70〜94%）だったので、
    「モデルとオッズを組み合わせて割安な艇だけ買う」方式にした。

【単勝の妙味】
------------------------------------------------------
  組み合わせ勝率 = モデル勝率^0.66 × オッズから見た勝率^0.43 （正規化）
  期待値 = 組み合わせ勝率 × 単勝オッズ が 1.10 以上の艇
  過去2,950レース（確定オッズで判断した場合）: 回収率124〜138%
  ※ 本番は締切前のオッズで判断するため目減りする。どれだけ目減りするかを
    記録モードで測っている（締切10/5/2/1分前のオッズを全部記録）

【自信度（5段階評定）】
------------------------------------------------------
  ◎のモデル勝率で 1〜5（5が最高）
    5: 58%以上   4: 46%以上   3: 36%以上   2: 28%以上   1: それ未満

【GitHub Actions 自動実行】
------------------------------------------------------
  ・その日最初の実行で、前日の競走成績を公式データから取り込み
    player_stats.json（選手の過去成績）を更新
  ・各レースの締切10分前・2分前・1分前: オッズを記録
  ・締切5分前: 予想・妙味判定・Discord送信（妙味ありのみ）・記録
  ・JST 21:50: 結果・確定オッズを取得して集計、Discordにサマリー
  リポジトリの Secrets に DISCORD_WEBHOOK_URL を設定すること。

【フォルダ構成】
------------------------------------------------------
  gamagori_race.py     -> 予想プログラム本体
  model_v5.py          -> 予想モデルの計算
  model_v5.json        -> 予想モデルの係数
  mbrace.py            -> 公式データの取得・選手の過去成績の更新
  player_stats.json    -> 選手の過去成績（毎日自動更新）
  results.py           -> 結果検証
  check_and_send.py    -> GitHub Actions 用の送信ループ
  snap_odds.py         -> オッズの記録
  判定ルール.md        -> 実弾に進む基準（事前登録）
  research/            -> モデルの学習・検証スクリプト（ローカル用）
  sent/                -> 本番の記録（予想・オッズ・日別集計）
  discord_webhook.txt  -> Discord の Webhook URL（自分で作成・公開しない）

【モデルを作り直すとき（開発用）】
------------------------------------------------------
  学習データは C:\Users\dash_\boatrace_data（リポジトリ外）にある。
  research/ のスクリプトを順に実行:
    download_mbrace.py → parse_mbrace.py → build_features.py →
    scrape_win_odds.py → train_production.py
  ※ 判定期間中はモデルを変えない（判定ルール.md）
